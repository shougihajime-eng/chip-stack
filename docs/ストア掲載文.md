## 長い説明文（ストアの詳細欄向け）

**Casino Ledger は、カジノとポーカーのプレイヤーのための「収支ノート」です。**

ラスベガス、マカオ、韓国、国内アミューズメント——どこで遊んでも、1回ごとの結果をさっと記録。あとは累積収支グラフ、勝率、時給、連勝・連敗記録まで、アプリが自動でまとめます。「なんとなく勝っている気がする」を、はっきりした数字に変えましょう。

**こんな方におすすめ**
- ポーカー（NLH / PLO）のキャッシュ・トーナメント収支をきちんと管理したい
- 海外カジノで複数通貨を使い、円換算でまとめて把握したい
- 自分の「勝てるゲーム・勝てる場所」をデータで知りたい
- 大切な記録を、安心して長く残したい

**主な機能**
- 🎴 1回ごとのセッション記録（ゲーム種別・キャッシュ/トーナメント・国・店舗・通貨）
- 💱 為替レート自動取得（USD・KRW・EUR ほか10通貨に対応／円換算）
- 📈 累積収支グラフ・月次推移・ゲーム別/場所別ランキング
- ⏱ 時給計算・最長連勝/連敗・トーナメントROI・ITM率などの分析
- 🏆 トーナメント対応（大会名・リエントリー回数・順位・ノーマネーフィニッシュ）
- ⭐ よく行くカジノのお気に入り登録でワンタップ入力
- 💾 ワンタップのバックアップ（保存）と復元。機種変更も安心
- ☁️ クラウド同期で、スマホとパソコンから同じ記録を表示
- 📤 CSV 書き出し / 読み込み（Excel でそのまま開ける）
- 📱 スマホのホーム画面に追加して、アプリのように使える

**データは、あなたの手の中に**
記録はお使いの端末の中に保存され、サーバーへ勝手に送信されることはありません。クラウド同期はあなたが押したときだけ。広告も、わずらわしい通知もありません。

**安心してお使いいただくために**
本アプリは20歳以上の方を対象としています。記録・分析のための個人用ツールであり、賭博を助長・あっせんするものではありません。賭けは余裕資金の範囲で、のめり込みにはご注意ください。
